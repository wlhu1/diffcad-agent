# DIffCAD Agent — Plant Stomata Intelligence

Conversational stomata detection and phenotyping platform powered by YOLO-OBB.

## Features

- **Stomata Detection**: Upload microscope images for real-time OBB (Oriented Bounding Box) detection
- **Batch & Video Processing**: Process multiple images or extract frames from videos
- **Phenotyping Metrics**: Stomata density, conductance, aperture dimensions, aspect ratios
- **Conversational Agent**: Natural-language interaction for research workflow
- **CSV Export**: Export results for publications and analysis
- **REST API**: Full API access for integration with other tools
