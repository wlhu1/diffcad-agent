API Documentation

RESTful detection and phenotyping endpoints for the DIffCAD Agent platform.

Detection

POST/api/detect/single
Detect stomata and apertures in a single microscope image. Returns OBB boxes, metrics, and overlay.
multipart/form-dataimage + paramsOBB overlay
POST/api/detect/batch
Process multiple images in batch mode. Returns results array with per-image metrics and aggregated summary.
multipart/form-datamulti-imagebatch metrics
POST/api/detect/video
Extract frames from uploaded video at configurable interval and run detection on each frame.
multipart/form-datavideo + frame_intervalper-frame results
POST/api/detect/frame
Detect stomata from a base64-encoded camera frame. Designed for live-capture workflows.
application/jsonbase64 imagelive capture

Agent & Session

POST/api/agent/chat
Send a natural-language message to the DIffCAD Agent. Context-aware: includes current detection results, plant type, and workflow state.
application/jsonmessage + contextconversational
GET/api/session/results
Retrieve all detection results for the current session.
query: session_id
POST/api/session/reset
Clear session data and reset state. Useful between experiments.
application/jsonsession_id

Export & Status

POST/api/export/csv
Export detection metrics for the current session as a CSV file. Includes density, conductance, aperture dimensions, and metadata.
application/jsontext/csv responsedownloadable
GET/api/status
Get platform status: backend health, model weight availability, device info, PyTorch/ultralytics versions.
no paramssystem info
