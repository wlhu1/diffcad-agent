POST/api/detect/single

Detect stomata and apertures in a single microscope image. Uses YOLO-OBB models for oriented bounding box detection. Returns metrics, overlay image, and detection boxes.

ParameterTypeLocationDescription
image requiredFileformJPEG / PNG / BMP microscope image
plant_type optionalStringformdicotyledons or monocotyledons (default: dicotyledons)
sample_type optionalStringformdestructive or nondestructive (default: nondestructive)
conf optionalFloatformConfidence threshold 0-1 (default: 0.5)
iou optionalFloatformIoU overlap threshold 0-1 (default: 0.7)
scale optionalFloatformScale in µm for real-world metrics (default: 100.0)
session_id optionalStringformSession key for grouping results (default: "default")
# Single image detection with dicot model curl -X POST https://diffcad-agent.onrender.com/api/detect/single \ -F "image=@stomata_sample.jpg" \ -F "plant_type=dicotyledons" \ -F "sample_type=nondestructive" \ -F "conf=0.5" \ -F "scale=100.0"
import requests # Single image detection with open('stomata_sample.jpg', 'rb') as f: files = {'image': f} data = { 'plant_type': 'dicotyledons', 'sample_type': 'nondestructive', 'conf': '0.5', 'scale': '100.0', } resp = requests.post(f"https://diffcad-agent.onrender.com/api/detect/single", files=files, data=data) result = resp.json() print(f"Stomata: {result['metrics']['stoma_count']}") print(f"Density: {result['metrics']['stoma_density_mm2']:.1f} mm⁻²")

POST/api/detect/batch

Process multiple images in parallel. Accepts images (plural) as multiple file uploads. Results sorted by order processed.

ParameterTypeLocationDescription
images requiredFile[]formMultiple JPEG / PNG / BMP files (field name: images)
plant_type optionalStringformSame as single detection
sample_type optionalStringformSame as single detection
conf optionalFloatformConfidence threshold (default: 0.5)
iou optionalFloatformIoU threshold (default: 0.7)
scale optionalFloatformScale in µm (default: 100.0)
session_id optionalStringformSession key
# Batch detection on multiple images curl -X POST BASE_URL/api/detect/batch \ -F "images=@sample_01.jpg" \ -F "images=@sample_02.jpg" \ -F "images=@sample_03.jpg" \ -F "plant_type=dicotyledons" \ -F "sample_type=nondestructive"
import requests files = [ ('images', ('s1.jpg', open('s1.jpg', 'rb'), 'image/jpeg')), ('images', ('s2.jpg', open('s2.jpg', 'rb'), 'image/jpeg')), ] data = {'plant_type': 'dicotyledons', 'sample_type': 'nondestructive'} resp = requests.post('BASE_URL/api/detect/batch', files=files, data=data) result = resp.json() for r in result['results']: m = r['metrics'] print(f"{r['file_name']}: {m['stoma_count']} stomata")
POST/api/detect/video

Extract frames from a video at the given interval and run detection on each extracted frame. Video file is deleted after processing.

ParameterTypeLocationDescription
video requiredFileformVideo file (mp4, avi, mov)
frame_interval optionalIntformProcess every Nth frame (default: 30)
plant_type optionalStringformdicotyledons / monocotyledons
sample_type optionalStringformdestructive / nondestructive
conf optionalFloatformConfidence threshold (default: 0.5)
session_id optionalStringformSession key
curl -X POST BASE_URL/api/detect/video \ -F "video=@microscope_video.mp4" \ -F "frame_interval=30" \ -F "plant_type=monocotyledons" \ -F "sample_type=nondestructive"
import requests with open('microscope_video.mp4', 'rb') as f: resp = requests.post('BASE_URL/api/detect/video', files={'video': f}, data={ 'frame_interval': '30', 'plant_type': 'monocotyledons', 'sample_type': 'nondestructive', }) result = resp.json() print(f"Processed {result['detected_frames']} frames")
POST/api/detect/frame

Detect stomata from a base64-encoded JPEG frame. Designed for live camera capture or real-time streaming scenarios. JSON body instead of multipart.

ParameterTypeLocationDescription
image_b64 requiredStringJSONBase64-encoded JPEG image data (without data: prefix)
plant_type optionalStringJSONdicotyledons / monocotyledons
sample_type optionalStringJSONdestructive / nondestructive
conf optionalFloatJSONConfidence threshold (default: 0.5)
session_id optionalStringJSONSession key
curl -X POST BASE_URL/api/detect/frame \ -H "Content-Type: application/json" \ -d '{"image_b64":"'"$(base64 frame.jpg)"'","plant_type":"dicotyledons"}'
import requests import base64 with open('frame.jpg', 'rb') as f: b64 = base64.b64encode(f.read()).decode() resp = requests.post('BASE_URL/api/detect/frame', json={ 'image_b64': b64, 'plant_type': 'dicotyledons', 'conf': 0.5, }) result = resp.json()
POST/api/agent/chat

Send a natural-language message to the DIffCAD conversational agent. The agent is context-aware: include current detection context for richer responses.

ParameterTypeLocationDescription
message requiredStringJSONNatural language message to the agent
context optionalObjectJSONDetection context: plant_type, sample_type, metrics, batch_summary, etc.
session_id optionalStringJSONSession key (default: "default")
curl -X POST BASE_URL/api/agent/chat \ -H "Content-Type: application/json" \ -d '{"message":"Summarize the last detection results","context":{"plant_type":"dicotyledons","metrics":{"stoma_count":23,"stoma_density_mm2":145.3}},"session_id":"my_session"}'
import requests resp = requests.post('BASE_URL/api/agent/chat', json={ 'message': 'What does stomata density of 145 indicate?', 'context': { 'plant_type': 'dicotyledons', 'metrics': {'stoma_density_mm2': 145.3}, }, 'session_id': 'my_session', }) result = resp.json() print(result['reply'])

POST/api/export/csv

Export all session results as a downloadable CSV file with full stomata and aperture metrics. Includes stoma count, density, conductance, dimensions, and per-image breakdown.

ParameterTypeLocationDescription
session_id optionalStringJSONSession key (default: "default")
# Download CSV results for a session curl -X POST BASE_URL/api/export/csv \ -H "Content-Type: application/json" \ -d '{"session_id":"my_session"}' \ -o stomata_results.csv
import requests resp = requests.post('BASE_URL/api/export/csv', json={'session_id': 'my_session'}) with open('stomata_results.csv', 'w') as f: f.write(resp.text) print('Exported results to stomata_results.csv')
